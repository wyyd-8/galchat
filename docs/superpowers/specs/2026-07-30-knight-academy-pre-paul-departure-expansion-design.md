# 《骑士学院》保尔离岛前世界包扩充设计

## 目标

扩充现有《骑士学院》世界归档 JSON，使世界状态由 KC2 二年级新学期开场推进至安格布尔护卫任务结束后、保尔离开克莱格岛之前。归档继续一次性提供世界、世界详情与 14 名核心角色，可被项目现有世界归档功能直接导入。

## 时间锚点

当前时间位于 KC2 第六章早段：

- 安格布尔校外教学与海洋大臣护卫任务已经结束。
- 袭击事件已经被阻止，可作为已经发生的非结局事件记录。
- 贝福里特已经结束哈什莱希公务并返回中央骑士团。
- 巴滕已经结束在学院的短期插班生活并返回鲁德维戈。
- 保尔仍留在克莱格岛，尚未离岛。

保尔只保留此时已经成立的状态：他仍是学院二年级生、阿尔戈的室友，并受无形边界限制而无法离开克莱格岛。不写他能够离岛、存在变得稀薄、告别、消失、死亡或此后的任何事件。

## 收录规则

可以写入：

- 时间锚点前已经发生的公共主线事件。
- 选项剧情中揭示、但不依赖恋爱成立或结局选择的稳定世界与人物事实。
- 已经公开或已经显现的 E.P.能力、职业经历、学习成果与当前职务。
- 不预设玩家恋爱选择的同学关系、师生关系和长期人物成长。

不得写入：

- 任何结局、后日谈、True/Normal/Bad Route 或恋爱成立结果。
- 互相冲突的选项状态和玩家对角色的固定感情。
- 保尔离开克莱格岛及之后的情节。
- 雅玛尔蒂雅之匣、雅玛尔蒂雅之钥、时间干涉或时间回溯机制。
- 卡培拉相关人物、历史、能力、物品、地点或事件。

最终 JSON 中不得出现“雅玛尔蒂雅”或“卡培拉”等相关名称，也不得以不点名方式保留对应的时间机制。

## 世界详情调整

保留现有世界架构、国家、学院、骑士、龙与 E.P.制度设定，并作以下调整：

1. 将“二年级新学期的学院近况”改写为时间锚点对应的“安格布尔任务后的学院近况”。
2. 记录安格布尔校外教学和护卫任务已经完成，袭击被阻止，事件体现未来情报、正式骑士指挥、学生协作与 E.P.应对能力。
3. 补充骑士护卫任务的实务流程：预先排查、可疑人员盘问、保护对象转移、现场接管和 E.P.犯罪与普通手段并行调查。
4. 保留“超常谜元”的一般定义，但不写被排除的具体物品、制造者或时间机制。
5. 删除现有七龙议会详情中的卡培拉历史；只保留议会、条约、会议周期、成员代表与国际权限等通用设定。

## 角色调整

角色集合保持为原有 14 人，不新增或删除其他人物。`initFavor` 继续表示对普通陌生人的自然亲和度，不随剧情时间推进而改变。

重点更新：

- 阿尔戈：补充对未来信息型 E.P.的熟练运用、安格布尔护卫任务经验和协调同伴的成长；不写时间回溯机制。
- 格兰特利：补充其能力兼具物质穿透与透明化特征，以及参与针对巴滕的协作训练。
- 奥斯卡：补充小说获奖、前往安格布尔接受采访和举办签书活动；仍未显现 E.P.
- 提奥：补充更稳定的瞬间移动运用、团队协作与紧急转移经验。
- 保尔：维持仍在克莱格岛且无法离岛的状态，只补充已经成立的料理志向与学院生活，不写后续变化。
- 尤利乌斯：保持四年级候补生与国外任务志向，可补充其 E.P.在战斗与非战斗场景的通用价值。
- 迪德里克：补充安格布尔校外教学和护卫见习的指导经验。
- 西利欧：补充对 E.P.研究的兴趣、治疗消耗与任务后方支援职责。
- 赫尔曼：改为已经觉醒使接触物体变硬或变软的 E.P.，写明发动时间与战术用途。
- 希埃亚特：保留龙、议会成员、学院资质审核者与被动读取情感的既有设定，不加入被排除内容。
- 巴滕：改为已经结束短期插班并返回鲁德维戈，补充其认可学生协作成长；战斗型 E.P.细节仍未公开。
- 菲力克斯：补充危险实验后的责任意识和对安全边界的成长，不写恋爱结果。
- 伽米尔：补充担任学级长、受伤后与菲力克斯改善合作的经历，不写恋爱结果；仍未显现 E.P.
- 贝福里特：改为已经归队，补全“拷贝”分身的已揭示机制，包括实体分身、独立行动、共享思考与感觉、本体不承受分身的物理伤害，以及对指挥、护卫和公务的用途；保留仍有更深机制未公开。

## 数据结构

继续使用现有 `WorldArchiveDTO` 归档结构：

- 根字段为 `formatVersion`、`world`、`details` 与 `characters`。
- 14 名角色均保留 `name`、`image`、`background`、`personality`、`cocPlayStyle`、`favorability` 与 `initFavor`。
- `image` 保持 `null`。
- `favorability` 阈值保持 `"0"`、`"25"`、`"50"`、`"75"`。
- `initFavor` 保持当前 0–24 的陌生人阶段数值。

## 校验

1. JSON 能被标准解析器读取，并通过项目世界归档服务测试。
2. 恰好包含 14 名唯一核心角色，且姓名沿用 KC1 译名。
3. 保尔背景和世界时间锚点均明确表明他仍在克莱格岛、尚未离岛。
4. 全文不得出现保尔离岛、存在弱化、消失、死亡或其后事件。
5. 全文不得出现雅玛尔蒂雅、时间干涉、时间回溯或卡培拉相关内容。
6. 全文不得写入结局、后日谈、路线名、告白成立或固定恋爱结果。
7. 新增事件、能力与关系均能回溯至 KC2 保尔离岛前的剧本文本。
