《克苏鲁的呼唤》中使用的关键术语，按拼音顺序排列。

1D100：见百分骰。

1D4、1D6、1D8、1D10等：标识骰子的数量及面数。

APP：外貌 （Appearance），属性的一种，见属性。

CON：体质（Constitution），属性的一种，见属性。

DEX：敏捷（Dexterity），属性的一种，见属性。

EDU：教育（Education），属性的一种，见属性。

INT： 智力 （Intelligence），属性的一种，见属性。

NPC： 由守秘人扮演的非玩家角色（Non-Player Character）。

POW：意志（Power），属性的一种，见属性。

SIZ：体形（Size），属性的一种，见属性。

STR： 力量（Strength），属性的一种，见属性。

百分骰：游戏中的大部分检定都需要用到 1D100，即百分骰。技能和属性值都用百分比表示。

半值：投掷1D100时，与角色技能或属性值的半值相对比，用于困难难度。

背景故事：用于定义调查员是何种角色。

濒死：生命值归零且处于重伤状态的角色即陷入濒死（见第120页）。

不定性疯狂：当调查员在游戏中的一天内失去1/5或更多当前理智值时，他将陷入不定性疯狂。不定性疯狂持续到角色被治愈或者恢复为止（见第156页）。

察觉检定：包括侦查、心理学和聆听技能，有时也包括追踪。

常规成功：骰点小于等于技能或属性值即为常规成功（第82页）。见难度等级。

成功等级：分为失败、常规成功、困难成功与极限成功四种。极限胜过困难，困难胜过常规，常规胜过失败（见第82页）。

成长标记：成功使用技能的调查员应该勾选那项技能旁边的选框（做标记或打勾）。在调查员幕间成长阶段，为标记过的技能进行成长判定，这些技能将有机会提升 1D10点。克苏鲁神话和信用评级不能获得成长标记（见第94页）。

惩罚骰：由守秘人在检定中添加。进行技能或属性检定时，掷百分骰和额外一颗十位骰。现在掷3颗骰子，一颗个位和两颗十位。使用结果更差（较高）的十位骰（见第 91页）。

大成功：1D100 的掷骰结果为“01”时，检定始终成功，并且能够实现可能达成的最有益的结果（见第89页）。

大失败：当通过检定所需的掷骰结果小于 50，而1D100 掷出96-100，或通过检定所需的掷骰结果大于等于50，而1D100掷出100时，检定始终失败，且通常会带来可能造成的最糟糕的结果（见第89页）。

抵近射击：目标在距离射击者敏捷值的二十分之一米范围内时，射击者得到奖励骰（见第113页）。

典籍、神话典籍：记载着克苏鲁神话知识的书，通常会使读者获得克苏鲁神话技能点数和法术。

调查员：玩家角色。

调查员幕间成长阶段：玩家更新其调查员的阶段（为提升技能进行掷骰等），通常发生在游戏结束或模组结束时（见第94页）。

对抗检定：双方各自进行检定，对比成功等级，成功等级更高的一方获胜（见第90页）。

疯狂发作：陷入疯狂时，调查员所经历的第一个疯狂阶段。取决于当时的状况，造成即时或总结症状（见第156页）。

孤注一掷：如果玩家能够证明孤注一掷的合理性，则为其提供第二次技能检定的机会。孤注一掷失败会带来非常糟糕的后果。战斗、追逐、理智和幸运检定不能孤注一掷（见第84页）。详见预示。

故事：见模组。

<!-- PDF页 400；书内页 387 -->

寡不敌众：角色在一轮中进行过反击或闪避后，之后所有对其的攻击都带有一颗奖励骰。每轮攻击次数超过1次的角色或怪物可以在攻击者获得奖励骰之前反击或闪避相同的次数（见第108页）。

贯穿：如果攻击者在攻击检定中取得极限成功，则表示贯穿武器或子弹恰好击中重要部位，会造成更大的伤害（见第103页）。

后果：孤注一掷失败所产生的负面结果（见第86页）。

护甲：减少所受的伤害。穿着防弹衣、怪物的天然鳞甲都能使其获得护甲。从伤害中减去护甲值，结果才是实际损失的生命值（见第33页）。

幻觉：陷入疯狂时，调查员可能产生幻觉，因此守秘人可以向玩家提供虚假信息。玩家可以通过验明现实检定来看破幻觉（见第162页）。

昏迷：当角色受到重伤时，若未能通过体质（CON）检定，其将陷入昏迷。昏迷的持续时间由守秘人决定。成功的急救或医学检定能够唤醒昏迷的角色（见第123页）。

基础值：未经训练的调查员成功使用一项技能的概率。有些技能无法轻易掌握，因此只有1%的基础值。基础值标注在角色卡上每个技能旁边的括号里（见第434页）。

极限成功：骰点小于等于技能或属性的五分之一值即为极限成功（第120页）。见难度等级。

急救：一项技能，可以为受伤的角色回复1点生命值，或者为濒死角色稳定伤势（见第65页）。详见治疗。

技能：一项明确的知识、技术或身体能力，特别属于调查员的可用能力。

技能检定：以1D100进行的检定，见常规成功、困难成功与极限成功。

奖励骰：由守秘人在检定中添加。进行技能或属性检定时，掷百分骰和额外一颗十位骰。现在掷3颗骰子，一颗个位和两颗十位。使用结果更好（较低）的十位骰（见第91页）。

近战：徒手或使用以肉体力量驱动的武器进行战斗，如出拳或挥剑。

精读：对神话典籍进行系统性研究。同一本神话典籍可以精读多次，每次所需的时间加倍（见第174页）。

模组：专为角色扮演设计的一系列故事，包括一系列事件的经过、角色数据、特殊规则和法术，以及调查员可能会发现的有趣或令人回味的描述。模组可能由守秘人自行设计，亦可使用已经出版的模组集或扩展书中的模组。

可选规则：这类规则作为标准规则的补充或替代，由守秘人决定是否使用。

克苏鲁：（在混沌元素语中读作“kuh-THOOloo”）在H.P. 洛夫克拉夫特的故事中首次登场，此后屡次在其他作者的作品中出场或被提及。

克苏鲁神话技能：这项技能体现角色关于宇宙诸神、神话存在、怪物和恶魔的知识（见第64页）。

困难成功：骰点小于等于技能或属性的半值即为困难成功（第82页）。见难度等级。

理智：每个调查员在游戏开始时都是神志清醒的，但随后的理智损失可能导致其陷入临时性、不定性甚至永久性疯狂。

理智检定：掷1D100，小于等于当前理智值则成功。成功的理智检定可能减少较少的理智值或根本不减少。而失败的理智检定总会损失更多理智值，甚至可能导致疯狂（见第154页）。

理智损失：经由令人不安的可怕经历（比如遭遇怪物）而损失的理智值的数量，通常需要掷骰决定（见第154页）。

理智值（SAN）：起始值等于角色的POW。该数值可能发生变动。最大理智值等于99减角色的克苏鲁神话技能点数。理智可能减少或增加，但不会自动回复。

临时性疯狂：在单次理智检定中失去5点或更多理智值时，调查员的精神将遭受重大创伤。进行一次智力检定，若通过，调查员会理解自己的遭遇，并陷入疯狂1D10小时（见第155页）。

灵感检定：玩家发现游戏陷入僵局时，他们可以进行灵感检定，守秘人会将他们引回正轨（见第199页）。

轮：见战斗轮和追逐轮。

略读：对神话典籍进行粗读。浏览全书，获得等于略读值（CMI）的克苏鲁神话技能点数。如果读者是相信者，则会造成理智损失（见第173页）。

冒险：见模组。

敏捷次序：用于战斗和追逐。角色的行动按照各自的敏捷（DEX）值从高到低依次进行（见第102页）。

<!-- PDF页 401；书内页 388 -->

魔法值（MP）：由POW 属性衍生。魔法值用于施法，是人类和其它智慧生命所固有的。当魔法值归零时，对魔法值的进一步的消耗都将从生命值中一比一扣除。魔法值每小时回复1点（见第176页）。

目标：玩家进行检定所希望实现的效果（见第82和194页）。

幕间成长：见调查员幕间成长。

难度等级：难度等级分为三种：常规难度、困难难度和极限难度（见第82页）。

轻伤：单次受到的伤害小于角色最大生命值的一半。角色不会因为轻伤而死亡（见第119页）。

人体极限：调查员无法与超过自身100 点或更高的属性相抗衡（见88页）。

闪避：用于回避近战及远程攻击的技能（见第63页）。

伤害：受到攻击和意外受伤被称为“受到伤害”，即对角色造成伤口或损伤。伤害从生命值中扣除（见第119页）。

伤害加值（DB）：由 STR与 SIZ相加衍生，见表1伤害加值和体格（第33页）。

深层魔法、深层版本：比通常版本更有效的法术变体。

神话等级：衡量神话典籍中记载的克苏鲁神话知识深度（见第175页）。

生命值（HP）：等于角色的CON 与SIZ 之和除以10并向下取整。圈出生命值以指示受伤（见第33和119页）。

守秘人：游戏主持者。守秘人知晓故事背后的秘密，负责描述场景，扮演非玩家角色和怪物。守秘人是游戏规则的最终裁决者，应尽力在游戏中保持公正平等。

属性：每位调查员都需要掷骰得到八项属性：力量（STR）、体质（CON）、体型（SIZ）、敏捷（DEX）、外貌（APP）、智力 （INT）、意志（POW）和教育（EDU）。理智值、魔法值和生命值等次要属性均由这八项属性衍生。属性决定角色的基本能力（见第30页）。

死亡：受到重伤的角色生命值归零时，若未能接受成功的急救（和医学），该角色将会死亡。此外，如果角色在一次攻击中受到的伤害超过其最大生命值，该角色必然死亡（见第120页）。

体格：用以衡量物理尺寸、力气和耐久性。还可用于体现生物和无生命体的大体比例。

骰子（D）：表示需要掷骰来决定游戏中发生的结果。

突袭：出人意料的攻击，可能会让对手措手不及（见第106页）。

五分之一值：投掷1D100时，与角色技能或属性值的五分之一值相对比，用于极限难度。

显明线索：守秘人认为不可或缺的线索，应该轻易将之交给玩家（见第202页）。

险境：在追逐中，险境出现在两个地点之间，可能会使角色受伤，或是减缓角色或载具的速度，通过险境需要进行技能检定（见第134页）。

现金：来自信用评级。调查员可以按照他们的意愿随时花费现金（见第46页）。

相信者：调查员可能间接认识到克苏鲁神话（如通过阅读神话典籍）而并不真的相信神话。当角色第一次正面接触神话时，扣除等同于其克苏鲁神话技能点数的理智值（见第179页）。

信用评级：决定角色可用的现金及资产的数量。还体现角色能够负担的生活水平（见第73页）。

兴趣技能：创建调查员时，玩家可以向任何技能投入INTX2点技能点（见第36页）。

幸运：体现角色在其无法掌控的事件上的运气。

幸运检定：当情况受外部环境主导时，用来确定调查员的命运（见第90页）。

寻找掩护：察觉自己将被射击的目标可以尝试寻找掩护，其进行闪避检定（见第113页）。

验明现实：玩家进行一个理智检定来尝试看穿幻觉（见第162页）。

医学：为受伤或患病的角色回复1D3点生命值。为濒死的角色进行治疗前，需要先通过急救稳定伤势（见第120页）。详见治疗。

移动速度（MOV）：角色在一轮中可以移动的距离（单位米或码）。全速奔跑的角色可以移动五倍于该数值的距离（见第33页）。

隐秘线索：如果玩家未能通过察觉检定，守秘人可以决定保留下来的线索（见第202页）。

永久性疯狂：如果当前理智值归零，调查员将陷入彻底的疯狂之中（可能需要在收容设施里度过余生），将其从游戏中移除（见第156页）。

预示：在孤注一掷之前，守秘人可以揭示检定失败后可能发生的后果--如果孤注一掷检定失败，这可怕的后果将会降临在调查员身上（见第85页）。

展示材料：守秘人交给玩家的文件或其它东西，通常是一些线索。

战斗轮 /追逐轮：弹性游戏时间单位，用于对照多位角色的移动、武器使用及技能使用。轮中的行动次序按照角色的 DEX 从高到低依次进行（见第102页）。

战技：使用格斗技能施展的战术动作，目的是实现单纯造成伤害以外的效果，如擒拿对手，解除武器，使对手失去平衡等（见第105页）。

战役：同一组调查员参加的一系列相互关联的模组。

知识/教育检定：一次教育检定。某些情况下，调查员所受训练和教育可为其提供额外见解。

职业：调查员的生活来源。

治疗：如果受伤的角色未受重伤，该角色可以每天自动回复1点生命值，否则需要进行检定，见重伤。急救和医学有助于恢复伤势。

重伤：如果从单次攻击中受到的伤害大于等于角色最大生命值的一半，角色即受到重伤。重伤的角色生命值归零可能导致其死亡（见第120页）。每周结束时，需要进行恢复检定。

追逐：追击或逃离时，在确定的位置进行的一系列行动。追逐可能在驾驶载具时发生，也可能徒步中发生（见第132页）。

资产：来自信用评级。以资产形式存在的财富在变现后才能被花费（见第46页）。

组合技能检定：将一次掷骰结果同时与多个技能相对比。根据情况不同，守秘人可能要求其中一个或所有技能都成功（见第55页）。

最大理智值：等于99减克苏鲁神话技能（见第155页）。

最大生命值：角色完全健康时的生命值。

## 第七版转换规则摘要

这一部分用于将早期版本《克苏鲁的呼唤》的数据转换为第七版规则。若你熟悉旧版本规则，会注意到第七版中的属性、技能、战斗与对抗方式都有调整；以下规则旨在用尽量少的步骤完成转换。

### 属性转换

旧版本中，调查员与非玩家角色的属性通常使用3-18范围，而第七版使用百分比范围。转换时，将旧版本属性乘以5即可获得第七版完整属性值；之后再按需要计算半值和五分之一值。

|---:|---:|
| 3 | 15 |
| 4 | 20 |
| 5 | 25 |
| 6 | 30 |
| 7 | 35 |
| 8 | 40 |
| 9 | 45 |
| 10 | 50 |
| 11 | 55 |
| 12 | 60 |
| 13 | 65 |
| 14 | 70 |
| 15 | 75 |
| 16 | 80 |
| 17 | 85 |
| 18 | 90 |
| 19 | 95 |
| 20 | 100 |

若旧版数据中有超出20的属性，也按相同方式乘以5处理。

### 幸运、生命值与理智

幸运值和生命值可以保持不变。理智（SAN）不再是属性，现在只用于设置起始理智值。魔法值、生命值与移动速度等次要属性按第七版规则重新计算即可。

### 伤害加值与体格

负伤害加值在第七版中进行了调整。转换旧版数据时，重新按第七版“伤害加值和体格”表计算即可。体格是第七版引入的数值，会在战技和追逐中被用到；体格由 STR 和 SIZ 衍生。

### 技能转换

完整技能对照表用于把旧版技能折算为第七版技能。通常处理方式如下：

- 旧版同名技能可直接使用原有百分比。
- 合并到第七版大类技能中的项目，归入新技能。例如踢击、拳击、头槌、擒抱、刀、棍棒等常归入格斗（斗殴）或对应格斗专攻。
- 某些武器技能被重新分类。使用表中最接近的第七版技能。
- 若旧版 NPC 或怪物只列出了少量数据，先转换主要属性、生命值、移动速度、护甲、攻击方式与理智损失；不必要为每项技能补全完整角色卡。

### 怪物转换

转换怪物时，通常保留其原有角色定位，并按第七版方式表达：

- 将旧版属性乘以5。
- 重新计算生命值、魔法值、伤害加值、体格和移动速度。
- 多种近战攻击可合并为一个“格斗”技能，保留不同攻击效果。
- 若攻击的主要目的不是造成伤害，而是抓取、吞噬、击倒、缴械等，改写为战技。
- 护甲、理智损失、特殊能力和法术保持其原本叙事功能，但用第七版术语重写。

> **示例：黑山羊幼崽**
>
> 旧版中黑山羊幼崽有多条触手，每条触手都可攻击。第七版写法可改为：每轮有4次触手攻击；每次攻击可造成伤害或抓住敌人。它也可以使用践踏攻击。武器行可写为“格斗80%（40/16），伤害等于伤害加值；践踏40%（20/8），伤害2D6+伤害加值”。

### 属性检定与对抗检定

需要进行属性检定时，将属性视作百分比值，按常规、困难、极限成功等级处理。

第七版不再使用旧版本中的对抗表，转而使用对抗检定。旧版中需要查对抗表的检定，都应转换为双方各自进行检定并比较成功等级。例如，旧版对抗表中“对抗 STR 16”的检定，在第七版中转换为对抗 STR 80。

### 毒性（POT）

旧版中许多毒物有毒性（POT）值。POT 越高，毒剂越致命。转换为第七版时，可将 POT 视作毒物的强度，要求受害者进行 CON 检定，按成功等级减轻伤害或影响；具体伤害仍由守秘人按毒物性质决定。

### 神话典籍

每一本典籍都标注有一个数值，表示角色阅读后可能获得的克苏鲁神话知识。第七版使用“略读”“精读”“神话等级”“理智损失”等项目描述神话典籍。转换旧版典籍时，保留书籍的叙事内容，按第七版典籍格式重写其阅读时间、克苏鲁神话收益、理智损失和可能包含的法术。

### 武器表注释

**伤害：** 掷骰决定武器的伤害。攻击检定取得极限成功时，伤害会增加。非贯穿武器取伤害最大值（若有伤害加值，也取最大值）。只有主动发起的攻击在取得极限成功时才会增加伤害；任何反击造成的伤害即使极限成功也不会增加。

**贯穿：** 表示该武器或该类武器能够造成贯穿。在攻击检定中取得极限成功即造成贯穿：取伤害最大值（近战武器再取最大伤害加值），并额外为武器伤害进行一次掷骰。反击不能造成贯穿。在超射程，极限成功才能命中目标时，只有大成功（掷出01）才能造成贯穿。

**基础射程：** 武器攻击的标准距离。

**每轮（攻击次数）：** 每个战斗轮中能够进行的攻击次数，不影响角色用该武器反击的次数。大多数枪械可以每轮射击一次而不承受惩罚骰；也可以射出更多子弹（在括号中列出的数值），但是每次射击都要承受一颗惩罚骰。

**弹容量：** 根据弹匣或弹鼓的尺寸不同，可能列有多个数字。

**价格：** 分为1920年代和现代。现代价格是收藏品市场的价格，而1920年代不是。

**时代：** 表示该武器在哪些年代可用。

**故障值：** 如果射击检定的骰点大于等于武器的故障值，不仅是射击者的失误--枪械根本没有开火。

**稀有：** 可能已经成为古董的武器；或是可供收藏的精致武器，可能并不合法。

### 额外武器规则

**+DB：** 加上伤害加值，该值因人而异。

**火焰与燃烧：** 燃烧伤害会在后续轮继续造成伤害，直到火焰被扑灭。守秘人可根据火势大小、燃料和角色行动决定伤害变化。

**短点射/全自动射击：** 一些自动武器可以切换至点射或全自动射击模式。平民通常无法取得这些武器。列出的“每轮”数值显示可在不承受惩罚骰时进行的攻击次数；超出该次数通常会带来惩罚骰。自动武器使用独立的自动武器规则。

**霰弹枪：** 根据距离（射程）不同，伤害被分为三档。达到第一档射程时使用第一项伤害；达到第二档射程时使用第二项；达到第三档射程时使用第三项。超过第三档射程则通常不受伤害。独头弹使用独立伤害：10号1D10+7，12号1D10+6，16号1D10+5，20号1D10+4。

**链锯：** 难以被用作武器。大失败概率加倍。大失败可能造成链条断裂、反弹、引擎停转、锯条卡住或脱轨，并可能伤及使用者。

**催泪喷雾：** 不使用抵近射击规则；目标须通过相应检定，否则被眩晕或暂时失能。

**炸药棒和手榴弹：** 对3米内角色造成4D10点伤害，6米内造成2D10点伤害，9米内造成1D10点伤害。

**阔剑地雷：** 弹道是密集射束流，杀伤范围以表内距离处理。

## 规则摘要

### 调查员成长与奖励

- 成功使用技能后，在技能旁作成长标记。
- 调查员幕间成长阶段，为有成长标记的技能进行成长判定。
- 成长判定失败时，技能增加1D10点。
- 若技能提升至90%或更高，增加2D6点理智值。
- 守秘人可在模组或战役阶段结束时给予理智奖励。
- 尝试回复理智值时，使用理智章节的恢复规则。

<!-- PDF页 421；书内页 408 -->

### 战斗摘要

1. 判断是否突袭。若目标没有察觉攻击，突袭者可能获得先手或自动成功；若目标察觉到危险，则按正常敏捷次序进入战斗轮。
2. 每位角色在自己的回合中进行一个行动：攻击、移动、施法、使用物品、闪避、反击、施展战技等。
3. 声明行动意图：造成伤害、闪避、反击或施展战技。
4. 根据意图选择检定方式。
5. 比较成功等级。常规成功、困难成功、极限成功和大成功依次提高；失败与大失败按规则处理。
6. 战斗检定不能孤注一掷。
7. 为成功的攻击掷骰决定伤害。贯穿武器在极限成功时取最大伤害、最大伤害加值，并额外掷一次武器伤害；钝器等非贯穿武器在极限成功时取最大伤害和最大伤害加值。
8. 扣除护甲，记录伤害、重伤、濒死或死亡状态。

#### 反击、闪避与战技

- **反击：** 被攻击者选择反击时，双方比较成功等级。成功等级更高者造成伤害且自己不受伤害。平局时，攻击者在对抗中获胜。若双方均失败，不造成伤害。
- **闪避：** 攻击者必须取得高于闪避者的成功等级，攻击才会命中并造成伤害。平局时，闪避者获胜。若双方均失败，不造成伤害。
- **战技：** 若目标不是单纯造成伤害（如缴械、擒拿、推倒），使用战技。战技成功时通常不造成普通伤害，而是应用战技效果。

### 远程攻击摘要

- 远程投射武器（如弓箭）的处理方式与射击类似。
- 投掷武器可以被闪避，处理方式与近战相同。
- 面对远程武器或投掷武器的攻击时，角色可寻找掩护。
- 使用依靠肉体力量的投掷或投射武器（包括弓和投石索，但不包括弩），武器伤害需要加上攻击者伤害加值的一半或完整值，依表而定。

<!-- PDF页 422；书内页 409 -->

### 护甲与射击

护甲减少角色受到的伤害：从伤害中扣除护甲值。若护甲值等于或超过伤害，攻击不会造成生命值损失。

射击者可以瞄准以获得优势；若瞄准期间移动或受到伤害，将失去瞄准带来的好处。

装填弹药：每个战斗轮可以为手枪、步枪或霰弹枪装填一定数量弹药，具体由武器、弹匣和场景决定。

<!-- PDF页 423；书内页 410 -->

### 自动武器、弹药与故障

自动武器可以进行短点射或全自动射击。每发子弹造成的伤害都要减去护甲值。

武器故障：攻击检定的结果大于等于武器故障值，表示武器故障而未能击发。故障可能意味着卡壳、弹药问题、机械损坏或枪械根本没有开火。

<!-- PDF页 424；书内页 411 -->

### 其他类型伤害

| 类型 | 伤害范围 | 说明 |
|---|---|---|
| 轻微伤害 | 1-3 | 通常不会致命，但可能造成疼痛、惊吓或小型伤口 |
| 中等伤害 | 4-9 | 几次此等级伤害后可能致人重伤 |
| 严重伤害 | 10-19 | 可能造成重伤或使普通人失去战斗能力 |
| 致命伤害 | 20+ | 两次此等级伤害可能使人死亡；一次也可能足够致命 |

**窒息和溺水：** 角色每轮进行一次体质检定；一旦体质检定失败，此后的每轮该角色都要受到伤害，生命值归零会导致死亡（无视重伤规则）。

**毒剂：** 体质检定极限成功将使毒药伤害减半。毒药可能会产生多种副作用，包括腹痛、呕吐、腹泻、抽搐、昏迷、幻觉或其它由守秘人决定的症状。

### 战斗流程

```text
建立攻击次序
  → 按 DEX 从高到低行动
  → 每名角色选择行动
  → 选择攻击 / 反击 / 闪避 / 战技
  → 进行相应检定并比较成功等级
  → 成功攻击造成伤害
  → 扣除护甲
  → 判断轻伤、重伤、濒死、死亡或继续战斗
```

战斗检定不能孤注一掷。

贯穿武器在极限成功时：最大伤害 + 最大伤害加值 + 额外一次武器伤害。

钝器等非贯穿武器在极限成功时：最大伤害 + 最大伤害加值。

### 战斗伤害流程

```text
受到伤害
  → 伤害是否大于等于最大生命值的一半？
      → 否：普通伤害，扣除生命值
      → 是：受到重伤，扣除生命值并标记重伤
  → 生命值是否降至0？
      → 否：角色仍可行动，按伤势处理
      → 是：若未重伤则昏迷；若已重伤则濒死
  → 濒死角色需要急救稳定
  → 未被稳定则可能死亡
```

### 追逐摘要

1. 确定参与追逐的角色或载具是否逃向同一方向。若分头逃离，为每组分别建立追逐。
2. 按 MOV 顺序分别排序每组追逐参与者。
3. MOV 高于所有追逐者的逃离者将成功逃脱。
4. MOV 低于最慢逃离者的追击者将无法参与追逐。
5. 放置追逐者：按 MOV 顺序放置追逐者，最慢的放在最后，按照 MOV 差值在其之前放置其它追逐者。
6. 放置逃离者：将最慢的逃离者放置在最快追逐者之前2个地点的位置，按 MOV 差值继续放置。
7. 在追逐中，险境和障碍可能导致伤害、延迟或迫使角色进行检定。

#### 载具与障碍

- 摧毁障碍：载具的每点体格造成1D10点伤害。
- 载具撞击也可作为武器使用，每点体格造成1D10点伤害。
- 当载具造成伤害时，载具自身也会受到伤害，该伤害等于其造成伤害的一半。
- 每10点伤害会使载具失去1点体格，无视低于10点的伤害。

<!-- PDF页 428；书内页 415 -->

### 追逐中的移动行动

追逐中，角色或载具依据 MOV 获得移动行动。移动行动用于在地点之间推进、跨越障碍、制造距离或缩短距离。守秘人应根据地形、速度、障碍和风险要求相应技能检定。

| MOV | 移动行动参考 |
|---:|---:|
| 5或更低 | 1 |
| 6-8 | 2 |
| 9-11 | 3 |
| 12-14 | 4 |
| 15+ | 5或更多，由守秘人裁定 |

### 追逐障碍与险境

| 类型 | 效果 |
|---|---|
| 障碍 | 阻挡前进；需要检定通过，否则停留或损失移动行动 |
| 险境 | 穿越时存在受伤或损坏风险；失败可能造成伤害或延迟 |
| 车辆碰撞 | 根据体格与速度造成伤害 |
| 掩护与射击 | 追逐中仍可射击，但应考虑速度、掩护、距离和惩罚骰 |

### 追逐伤害与速度

追逐中的碰撞、跌落、障碍和险境都可能造成伤害。守秘人应根据速度、体格、落差和环境危险程度选择伤害。载具失控、撞击或穿越危险地形时，可能同时伤害乘员与载具。

### 追逐终止

追逐可在以下情况结束：

- 逃离者成功拉开足够距离并脱离视线。
- 追击者追上逃离者并迫使其停下。
- 一方失去行动能力、载具损坏或放弃追逐。
- 场景目标改变，进入战斗、交涉或其它场景。

### 理智与疯狂摘要

1. 遭遇恐怖事件时进行理智检定。
2. 成功时损失较少理智值，失败时损失较多理智值。
3. 单次理智检定损失5点或更多理智值时，进行智力（INT）检定；若成功，调查员理解所遭遇之事并陷入临时性疯狂。
4. 一天内失去当前理智值五分之一或更多时，调查员陷入不定性疯狂。
5. 当前理智值归零时，调查员陷入永久性疯狂，并通常从游戏中移除。
6. 疯狂发作分为即时症状与总结症状，按场景是否仍在进行决定使用哪一类。
7. 疯狂期间，守秘人可以通过幻觉、恐惧、妄想或行为冲动表现调查员的精神状态。
8. 玩家可以尝试验明现实，以识破幻觉。

### 理智奖励与恢复

完成模组、阻止神话威胁、拯救他人或达成调查目标后，守秘人可以给予理智奖励。奖励应与威胁规模、角色付出和故事结果相称。

理智恢复通常需要安全环境、时间、休养、心理治疗、亲友支持或完成个人目标。若调查员继续接触神话，其最大理智值仍受克苏鲁神话技能限制。

### 经验奖励

守秘人可在模组结束时给予技能成长机会、理智奖励、信用评级变化、人脉变化、背景故事更新或其它叙事奖励。奖励不应只体现“胜利”，也应体现调查员在恐怖事件中付出的代价。
